## Hi, I'm Hiroyura 👋

I make small, free Windows tools that do one job well. No accounts, no telemetry, no network access unless the job needs it.

### Apps

| App | What it does | Get it |
| --- | --- | --- |
| [TekuTeku File Merge](https://github.com/hiro5791/FileMerge) | Combines several files into one, byte for byte.
